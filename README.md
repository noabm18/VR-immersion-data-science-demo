# VR-immersion-data-science-demo
Repository for my demo project checking the amount of movement while doing VR with how long people are able to run their sessions for


# VR Movement and Engagement Analysis

## Research question

Is reduced physical movement during VR associated with longer sessions?

## Candidate hypotheses

1. Sessions with less head or body movement are associated with longer duration.
2. Cybersickness may explain part of the relationship between movement and
   session duration.

## Important limitation

This is initially an observational analysis. A relationship between movement
and session duration would not demonstrate that reduced movement causes greater
immersion. Longer sessions could instead reflect comfort, application type,
user experience, or reduced cybersickness.
